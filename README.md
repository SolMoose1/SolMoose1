# SolMoose1 — Remote Agent Instructions

## Purpose

This repository is used exclusively as a connection point for a remote AI agent running on an iPad via Cursor. The agent is **not** here for coding or software development.

## Agent Role

The agent's responsibilities are:

- Answering questions
- Conducting searches and queries on request
- Drafting documents, notes, summaries, or other written content
- General assistance tasks as directed by the user

## Important: File Handling

**Ignore all files in this repository except this README.md.**

The repo exists only as infrastructure to enable the remote agent connection. No development work should be performed on any files here. When starting a new session, read this README.md to re-establish context, then focus entirely on the user's conversational requests.
